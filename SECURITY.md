# Security

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/rcgiri-physics/pdf-render-pool/security/advisories/new) rather than a public issue. This is a small project maintained in spare time, so replies may take a few days.

## Rendering untrusted content

Rendered HTML runs in a real browser on your server. See the [Security section of the README](README.md#security) before rendering anything a user can influence.
